# ASIAN PAINTS LTD. FINANCIAL MODEL
Three-Statement Forecasting, and DCF Valuation and Report

## Disclaimer

This project has been developed solely for educational and portfolio purposes.

The valuation should not be considered investment advice. Forecasts and assumptions involve uncertainty and may differ from actual future performance.

A comprehensive financial model of **Asian Paints Limited** built entirely in Microsoft Excel. This project demonstrates end-to-end equity valuation using the **Discounted Cash Flow (DCF)** methodology based on **Free Cash Flow to Firm (FCFF)**.

The model integrates historical financial statements, forecasting, valuation techniques, sensitivity analysis, and an interactive dashboard visualising Profitability, Valuation and Cash Flows of the firm.

## Valuation Methodology

### Discounted Cash Flow (DCF)

Enterprise Value calculated using:

- Free Cash Flow to Firm (FCFF)
- Weighted Average Cost of Capital (WACC)
- Terminal Value (Gordon Growth Method)
  
Intrinsic Equity Value is obtained after adjusting for:

- Net Debt

Finally,

Intrinsic Share Price =
Equity Value ÷ Outstanding Shares
